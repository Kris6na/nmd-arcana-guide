Scope of This Guide

Covers High-Tier (4-Rune) Arcana Sets exclusively. Low-Tier (2-Rune) and Mid-Tier (3-Rune / 4-Rune) sets are excluded, as are unverified RNG hypotheses.

Tier Mixing Warning

Divine Blessing exists in both Mid-Tier (+30 to +300 Element ATK) and High-Tier (+50 to +500 Element ATK). Never mix tiers or the Set Skill will not activate.

01

Arcana System Basics & 4SE Farming

Activating a High-Tier Set

  • 4-Element Match: Equip 4 High-Tier Runes of the exact same set name—one from each element (Wind, Lightning, Water, Fire).
  • Ninja Element Lock: The 4 offensive sets require deploying a Ninja of the matching element. Divine Blessing works with any Ninja.
  • Default Trigger Limit: Every Set Skill triggers once per battle by default unless extended by a Wind or Lightning Special Effect.

Weekly Rune Farming (4SE)

  • Rotating Portals: Each week, the weekly mode 4SE opens 2 elemental portals rotating among Wind, Lightning, Water, and Fire.
  • Element Entry Rule: You must enter each portal using Ninjas of the matching element to defeat its bosses and farm Runes of that element.
  • RNG Rolls: All Rune Effect values and Lv. 8 Secondary Base Stat values are RNG-generated within fixed ranges.

Rune Anatomy & Upgrade Milestones

Base Stats Active from Battle Start

  • Primary Base Stat (Lv. 1–10): Fixed [Element] Element ATK starting at +50, scaling by +50 per level up to +500 at Lv. 10 (+2,000 total across 4 maxed Runes).
  • Secondary Base Stat (Lv. 8): Unlocks 1 permanent passive stat from a 6-stat pool: Raw ATK, Weapon ATK, Ninjutsu ATK, Max HP, Effect Resistance (Effect %), or Score Bonus (Score Bonus %). Remains fixed at its Lv. 8 roll through Lv. 9–10.

Rune Effects Dormant Until 1st Set Trigger

  • Effect Slot 1 (Lv. 1): Rolls either that element's Special Effect OR a Common Effect from that Set × Element pool.
  • Effect Slot 2 (Lv. 5): Unlocks a second line drawn strictly from the Common Effect pool (never a Special Effect). Uses the exact same RNG range as Lv. 1 and can duplicate Slot 1's Common Effect.

Common Effects & Set-Wide Caps

Every High-Tier Rune draws its Common Effects from a 5-stat pool per element: 1 Element-Exclusive Multiplier/ATK stat + 4 Universal Cross-Element Utility stats.

05

Relay & Bonus Activation Rules

First Relay Timer Reset

Relaying into your 2nd Ninja with Lightning's First Relay Activation fires the Set Skill immediately, turns on all Common Effects (including Permanent ATK), and resets your normal countdown timer to 100% so your regular trigger remains available later.

Relay Limit in Boss Fights

Standard Boss battles allow 1 relay. Special ultra-high-HP Boss events allow up to 2 relays—the 2nd relay grants no relay activation bonus and simply continues the running timer.

Bonus Activation Re-Triggers

When Wind (+1 Activation) or Lightning (First Relay) triggers the set again, all Common Effects re-trigger (healing again and refreshing/stacking 10s buffs up to caps)—except Permanent ATK, which stays at 1 stack per line for the entire battle.
