3.3 Relay

Your 1st relay always restarts the countdown that is currently running, even without the Skill Activation on Relay attribute. That attribute adds an instant activation on top of that. Your 2nd relay does nothing.

When you relayWhat happens
Before the skill has activated for the first time The first activation’s countdown restarts. The additional activation’s countdown only starts after the first activation, so it isn’t affected yet.
After the first activation, before the additional activation The relay restarts the additional activation’s countdown.
After the skill has used all its activations Nothing to reset. A relay only triggers the skill if you have the Skill Activation on Relay attribute.
2nd relay No effect.

Skill Activation on Relay doesn’t depend on a countdown, so it always triggers on your 1st relay, whatever the element of the starting Ninja or the relaying Ninja.

5.3 Second Class Attribute Pool

  • Can be obtained from specific element runes only.
  • Can be equipped in the Rune Attribute (I) and (II) slots.
  • Can be obtained at rune Level 1 and 5 only.

5.3.1 Permanent ATK Boost (Wind Element Runes Only)

  • Gain a permanent stack of +50 to +120 ATK after the first skill activation.
  • Can stack with identical attributes. No known cap.
  • Additional skill activations do not add more stacks. It only stacks once from the first skill activation.

5.3.2 Skill Crit DMG (Lightning Element Runes Only)

  • Gain +14% to +30% Crit DMG for the arcana skill.
  • Can stack with identical attributes. No known cap.

5.3.3 Skill DMG Increase (Water Element Runes Only)

  • Gain +10% to +15% DMG for the arcana skill.
  • Can stack with identical attributes. No known cap.

5.3.4 Skill Crit Rate (Fire Element Runes Only)

  • Gain +5% to +25% Crit Rate for the arcana skill.
  • Can stack with identical attributes. No known cap.
